# Machine tags

`tag-07.png` is the FM-200 pump skid's tag (Fieldmate tag 7). Print it so the **black square is 20 cm** on a side
(the white margin around it is part of the tag; don't trim it), matte paper, no scaling to fit.

Lay it flat on the floor where the machine's **front edge** should be, upright as you read it from the front. In the
headset: hand menu → **Scan tag**, look at the tag from about a metre. The skid appears standing just behind it, facing
you. Regenerate the image with `Fieldmate > Set Up Machine Tags`.

Tags are 7×7 cells (black border, 5×5 data), 32 ids, any two at least 6 cells apart in every rotation: a tag still reads
with two cells wrong. The detector runs on the headset; no image leaves it.
